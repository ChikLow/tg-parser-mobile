# TG Parser — телеграм парсер на телефоні

Веб-застосунок (PWA), який парсить Telegram **прямо з браузера телефона**. Додається на домашній екран і запускається як звичайна програма — без серверів, без комп'ютера, без встановлення чогось із магазину.

## Що вміє

**Повідомлення**
- збір історії будь-якого каналу, групи чи чату, до якого має доступ твій акаунт
- пошук на сервері Telegram (швидко) + власні ключові слова: будь-яке / усі одразу / регулярний вираз
- фільтри: період дат, тип вкладення (фото, відео, документи, музика, голосові, GIF, кружечки, посилання), тільки з медіа, тільки з текстом, мінімум переглядів, конкретний автор
- живий прогрес: скільки переглянуто, скільки знайдено, швидкість, до якої дати дійшли; збір можна зупинити будь-коли й зберегти вже зібране

**Учасники**
- вивантаження списку учасників груп і каналів (де Telegram це дозволяє)
- «глибокий пошук» — перебір за літерами, щоб обійти ліміт у ~10 000 профілів
- ім'я, username, ID, телефон (якщо відкритий), статус, бот/premium

**Робота з результатом**
- пошук і сортування всередині зібраного (за датою, переглядами, реакціями, довжиною)
- статистика: активність за днями, топ авторів, часті слова, розподіл вкладень
- експорт у **CSV / JSON / TXT / HTML** — зберегти у «Файли» або одразу надіслати через системне «Поділитися»
- завантаження медіа з конкретного повідомлення

## Як запустити на телефоні

### 1. Опублікувати сайт (робиться один раз)

Це не звичайна HTML-сторінка, а застосунок, який треба **зібрати** — просто ввімкнути Pages на робочій гілці недостатньо (сайт віддаватиме вихідний код і зависне на заставці). Збірку робить GitHub Actions при кожному push, складаючи готові файли в гілку `gh-pages`:

1. Дочекайся зеленої галочки в **Actions** (workflow «Build and publish to gh-pages»).
2. **Settings → Pages → Source: Deploy from a branch → Branch: `gh-pages` → `/ (root)` → Save**.
3. За хвилину сайт буде тут: **https://chiklow.github.io/tg-parser-mobile/**

Якщо крок публікації впав із `403`: **Settings → Actions → General → Workflow permissions → Read and write permissions**.

Будь-який інший статичний хостинг теж підійде — потрібна лише HTTPS-адреса:

```bash
npm ci
BASE_PATH=/ npm run build   # готовий сайт у dist/
```

### 2. Отримати ключі Telegram API

1. Відкрий [my.telegram.org/apps](https://my.telegram.org/apps), увійди за своїм номером.
2. Якщо застосунку ще немає — створи: App title і Short name будь-які (напр. `parser`), платформа Web/Other.
3. Скопіюй **App api_id** і **App api_hash**.

Ключі потрібні, бо застосунок працює як повноцінний клієнт Telegram, а не як бот. Вводяться один раз.

### 3. Додати на домашній екран

- **Android / Chrome:** відкрий сайт → меню «⋮» → «Встановити застосунок». Або кнопка «Встановити» на вкладці «Ще».
- **iPhone / Safari:** відкрий сайт → «Поділитися» → «На екран «Додому»» → «Додати».

Далі — звичайна іконка на екрані. Всередині: api_id, api_hash, номер, код із Telegram, за потреби пароль двоетапної перевірки.

## Приватність

- Застосунок з'єднується з серверами Telegram **напряму** з телефона (MTProto через WebSocket). Проміжного бекенду не існує — сайт це лише статичні файли.
- api_id, api_hash і ключ сесії лежать **тільки** в локальному сховищі браузера. На вкладці «Ще» є перемикач «Пам'ятати вхід» (для спільного пристрою) і кнопка «Стерти всі дані».
- Ключ сесії = доступ до акаунта. Сесію завжди можна відкликати: Telegram → Налаштування → Пристрої.
- Зібрані персональні дані (імена, ID, телефони) використовуй лише законно.

## Обмеження, про які варто знати

- **FLOOD_WAIT.** За надто швидкі запити Telegram просить зачекати. Застосунок показує таймер і продовжує сам. Пауза між запитами налаштовується (за замовчуванням 1 с).
- **Учасники.** У більшості каналів список видно лише адміністраторам, а Telegram віддає щонайбільше ~10 000 профілів на запит — звідси опція «глибокий пошук».
- **Телефони** видно тільки тим, кому їх відкрито налаштуваннями приватності.
- **Приватні запрошення** (`t.me/+…`) не відкриваються з застосунку: спершу приєднайся до чату в Telegram, потім обери його у списку «Чати».
- Дуже інтенсивний парсинг новим акаунтом може призвести до обмежень з боку Telegram.
- Результати живуть у пам'яті вкладки — експортуй їх одразу після збору.

## Розробка

```bash
npm ci
npm run dev       # http://localhost:5173 (доступний і з телефона в тій же мережі)
npm run build
npm run preview
```

Стек: Vite + GramJS (MTProto-клієнт), чистий JavaScript без фреймворків, `vite-plugin-pwa` для офлайну та встановлення.

```
src/
  main.js       навігація і запуск
  tg.js         MTProto: вхід, чати, парсинг, учасники, медіа
  state.js      збереження налаштувань і сесії на пристрої
  export.js     CSV / JSON / TXT / HTML
  ui.js         DOM-хелпери, тости, модалки
  screens/      екрани: вхід, чати, парсер, результати, налаштування
```
